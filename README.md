# Cybersecurity Roadmap

Интерактивный учебный roadmap по кибербезопасности (направление SecOps / AppSec).
Это "не" README-интерфейс — открывай `index.html` (или ссылку на GitHub Pages), README нужен только для того, кто дорабатывает проект.

## Что это

Статический сайт: карта из 11 этапов, каждый со своими темами и маленькими
проверяемыми пунктами (📖 теория / ⌨️ практика / 🧩 challenge / 🛠️ project).
Прогресс — чекбоксы, которые пересчитывают progress bar каждой темы, этапа
и общий прогресс, и сохраняются в `localStorage` браузера.

## Как запустить локально

Открыть `index.html` двойным кликом не сработает — `script.js` подгружает
`roadmap/roadmap.json` через `fetch`, а браузеры блокируют такие запросы с
`file://`. Нужен локальный сервер, например:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Как разместить на GitHub Pages

1. Запушить репозиторий на GitHub.
2. В настройках репозитория → "Pages" → Source: "Deploy from a branch" → `main` / `root`.
3. Через пару минут сайт будет доступен по адресу вида
   `https://<username>.github.io/<repo>/`.

## Как редактировать roadmap

Весь контент лежит в `roadmap/roadmap.json`, интерфейс генерируется из него
автоматически — вручную редактировать HTML не нужно.

Структура одного этапа:

```json
{
   "id": "s2",
   "icon": "🐧",
   "title": "Linux",
   "subtitle": "Короткое описание этапа",
   "topics": [
      {
         "id": "s2-t1",
         "title": "Название темы",
         "sections": {
            "theory": [
               {
                  "id": "s2-t1-th1",
                  "text": "Понять, что такое ...",
                  "links": [
                     { "label": "Название ссылки", "url": "https://..." }
                  ]
               }
            ],
            "practice": [
               { "id": "s2-t1-pr1", "text": "Сделать что-то руками" }
            ],
            "challenge": [],
            "project": []
         }
      }
   ]
}
```

Правила:

- "`id` каждого пункта должен быть уникален" во всём файле — это ключ, по
  которому сохраняется прогресс. Не переиспользуй чужой `id` и не меняй его у
  уже отмеченных пунктов, иначе прогресс по нему «потеряется».
- Секции `theory` / `practice` / `challenge` / `project` необязательны — если
  список пустой или отсутствует, блок просто не рисуется.
- `links` у пункта — необязательный массив `{ "label": "...", "url": "..." }`.
  Для локального материала можно указывать относительный путь, например
  `"url": "materials/linux/permissions.pdf"`.
- Формулируй пункты как маленькое проверяемое действие («Изменить права файла
  (chmod)»), а не как абстрактную тему («Изучить права доступа»).

## Экспорт / импорт прогресса

Кнопки «Экспорт» и «Импорт» в шапке сайта сохраняют и загружают JSON-файл с
отметками — так прогресс можно перенести на другой компьютер или браузер.
